## Automated evidence

The .NET 8 Release suite passes 8/8. It covers framing and validation, sample sequence/session/epoch transitions, oversized/truncated/malformed frames, a real Host process with synthetic publisher and typed view readers, a large UT jump and latest-only state, Host restart, concurrent publisher rejection, reconnect, stale detection, eight parallel view reads, and recovery after 16 stalled view clients. Synthetic publishers are test-only and are not launched by the normal Manager script. Core, Host, Manager, and bridge Release builds completed with zero warnings/errors against the local KSP references. The WPF process launched and remained responsive; its pixels were not inspected because the test did not take desktop control.
